# UI-SECT-GATE-PORTRAIT-R1：新版山門圖構圖與顯示

2026-11-06，依使用者要求調整宗門首頁相關圖片，承接 ROADMAP 的 SECT-REFORM 與 UI-JOURNEY-LAYOUT-B-R1。相依的五宗山門與全高雙欄已存在；本次只處理五宗首頁插畫及顯示，完成狀態見 [development-status](../development-status.md#ui-sect-gate-portrait-r1)。

## 問題與交付

原五圖皆為 1672×941 橫圖；新版首頁在左側導覽之外，以窄長視覺欄配右側全高閱讀欄。原圖 contain 後只佔中間一條；直接 cover 則會裁掉宗門識別建築。本次以既有五圖各自作編輯輸入，重構為 1024×1536（2:3）直式插畫，另存 `assets/ui/sect-life/*-gate-portrait.png`。

構圖由下方步道、中段完整山門、上方遠殿與山霧串接；保留太虛書卷、天劍巨劍、縹緲藥圃、萬佛蓮池、紫霄觀星與雷法的既有識別。維持紙感水彩、淡雅配色，不把宗名、操作或規則文字畫入圖片。這是靜態 UI 敘事插畫，不是可互動世界場景或新建築。

## 顯示規劃與接線

- 以 `SectLifeFolio` 實際內容高度判斷：至少300邏輯px載入直圖；不足300沿原短式布局載入原橫圖。使用內容高度而非裝置名稱或固定視窗尺寸，視窗改變時可還原。
- 沿原 TextureRect 的 `EXPAND_IGNORE_SIZE`＋`KEEP_ASPECT_CENTERED`，完整等比呈現；不拉伸、不裁屋頂，也不將圖檔原始尺寸變成容器最小尺寸。
- 左側五宗分頁、右側18px正文單區內捲、比較及固定拜入操作保持原有接線；圖片忽略輸入，切圖只變呈現，不送命令、不改庫存／保存／RNG。
- 同門立繪、坊市／秘術圖示與大比不屬本次橫圖問題，不替換。新增圖與舊圖並存，日後其他直式山門圖沿相同構圖與載入策略。
- 僅載入當前宗門的所需版型，路徑不變時不重載；不預先建立十個顯示節點。原橫圖供短高度使用。

## 來源與分層

使用內建 image_gen，各宗一個獨立編輯呼叫。輸入為本專案2026-11-05已接受的五宗 AI 山門圖，沿原來源紀錄；未新增第三方參考圖或主張第三方商用授權。每張一層不透明靜態背景，UI文字／操作仍為獨立Godot節點，沒有新增霧／燈光動效層。提示詞、原輸入及輸出雜湊、生成檔案來源與用途見 [manifest](gate-portrait-r1/manifest.json)，提示詞在同目錄 `prompts/`。原生成圖逐位元組複製到專案，沒有裁切、拉伸、重繪後處理。

## 驗收範圍

L1／L2選取 `sect_life_ui_runner.gd`、`sect_tournament_ui_runner.gd`、`uix_r9_sect_ui_runner.gd`，以1280×720單一視窗執行；山門runner檢查五宗正式資源、2:3比例、視覺高度使用率、低內容高度切回橫圖及還原、原拜入命令與同門立繪。局部內容高度變化屬同視窗的元件行為驗證，不是全尺寸矩陣。原生渲染另以同runner的 `DAO_GATE_CAPTURE=1` 取得五宗畫面。

UI L2另需含本次修改的桌面Chrome 1280×720滑鼠抽驗：進入未入宗首頁、逐一切換五宗、查看比較／捲動與拜入按鈕。工具阻擋時標示待驗，不以原生畫面代稱Chrome通過。只更新本機Web，不製作候選包，不觸發L3。正式美術接受由使用者回饋決定。
