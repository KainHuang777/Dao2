## 2. 設計原則

1. **遊戲 HUD，不是軟體面板**：常駐畫面只留「我是誰（境界）、我現在要做什麼（任務）、我有什麼（焦點資源）、我能去哪（導航）、我能立刻做什麼（主行動）」。其餘全是**情境式、按需出現、一次只開一個**。
2. **資源跟隨「成本」，不跟隨「頁面」**（見 §4）。
3. **圖形優先、文字輔助**：資源＝圖示＋數字；建築＝圖卡＋等級點＋進度環；滿倉用發光／缺口表示，不寫 `[滿]`。
4. **不改規則、不改存檔**：只動 Godot 表現層，仍讀 Session view、送既有命令（符合 AGENTS.md）。

## 4. 何時開什麼介面、何時顯示資源（問題 1–2）

**層級**：L0 世界 → L1 常駐 HUD → L2 情境面板（同時只一個，停靠右側；短橫式改底部抽屜）→ L3 演出／彈窗 → L4 通知。

**核心規則**：資源晶片列顯示與否 = 「該頁的操作成本是否依賴全域庫存，且頁面沒有就地顯示 擁有／需要」。

| 情境 | 資源顯示 | 理由 |
| --- | --- | --- |
| 洞府（首頁） | 焦點資源晶片列；點開儲物袋看全部 | 需隨時掌握產出與滿倉 |
| 經營→建築 | 面板頂部只顯示「清單內建築成本會用到」的 3–5 枚晶片；每張建築卡就地顯示 擁有/需要（綠/紅） | 判斷能否升級的資料就在卡上，全域列可收起以讓出地圖 |
| 經營→空島／製造／運輸 | 不顯示全域列；製造／運輸沿用 R2–R5 的就地材料格；寬螢幕保留祖島庫存側欄（現行行為） | 這些頁已經是成本內嵌式 |
| 修行（技能／煉丹／靈獸…） | 只在面板標題列顯示該頁貨幣（技能點、靈草、獸魂…） | 避免與無關資源混雜 |
| 遊歷（九界／宗門／機緣…） | 全部隱藏；頁內顯示自己的貨幣 | 這些是敘事／決策頁，資源干擾大 |
| 突破／輪迴／離線總結演出 | **整個 HUD 隱藏**（只留跳過） | 電影化，不洩漏數字 |

**開啟規則**：
- 點世界建築 → 在建築旁彈**迷你情境卡**（升級／詳情），而不是直接開整個右欄；
- 點 Dock → 開對應群組面板並記住上次分頁（現行行為保留）；
- 任務卷軸「前往」與紅點 → 深連結 `open(route)`（沿用現行 canonical route，不開第二份面板）；
- 面板開啟時：相機自動讓位（現行規格已有）、左上圓徽縮為最小、主行動鈕保留。

## 5. 分頁設計（問題 3）：由 5 種變成「3 級、各一種形狀」

| 級別 | 用途 | 建議形式 | 為什麼 |
| --- | --- | --- | --- |
| **T1 Dock** | 4 個主入口 | 底部玉印**圓形圖示鈕**＋短標＋紅點 | 一級導航要像遊戲主選單，且與其他按鈕形狀完全不同 |
| **T2 頁面分頁** | 同一面板內切換內容（建築／空島／製造／運輸；技能／煉丹…） | **書籤式分頁，掛在面板上緣**，選中者凸起並與面板相連；有圖示＋2–4 字；窄螢幕未選中者縮成圖示，超出時橫向捲動＋邊緣淡出 | 一眼看出「這些分頁屬於這張面板」；取代獨立飄浮分頁列＋「返回洞府」；返回改為面板角落**✕ 印鈕**（Dock 的「洞府」也能返回） |
| **T3 篩選／分段** | 內容內的篩選（全部／生產／倉儲、島別、精煉／合成、宗門三頁） | **小藥丸（pill）晶片**，尺寸明顯小於 T2、不凸起 | 避免與頁面分頁混淆 |

附帶調整：
- 移除資源「關閉／數量／完整」三段切換 → 改為「點晶片列展開儲物袋」（**會動到 docs/07 的三態契約，需你同意**，見 §8）。
- 宗門面板自建的三分頁 → 改用 T3 元件。
- 島選擇（祖島／青木／玄礦／丹霞）→ T3 變體：小島圖示晶片＋狀態點（運轉／閒置／受阻），本輪**只定規格**，不改。
- 側向替代方案：若某群組頁面 ≥7 個，改左側垂直圖示欄；目前最多 5 個，建議維持頂部書籤。

## 6. 分頁與開放進度（問題 4）：三態

| 狀態 | 顯示 | 使用時機 |
| --- | --- | --- |
| **隱藏** | 完全不出現（不留空位） | 前置條件還差 ≥2 步，或內容會劇透後期（例：運輸、天道決策、輪迴天賦在尚無資格時） |
| **預告** | 灰階＋鎖＋一行解鎖條件（如「築基開放」「建藏經閣」） | 正好是「目前任務的下一步」或只差 1 個明確條件，讓玩家知道有目標 |
| **可用** | 正常；有新內容時顯示紅點 | 條件已滿足 |

- **單一事實來源**：新增一個**純讀取**函式（建議 `src/presentation/feature_unlocks.gd`，輸入 Session view，輸出每個 route 的三態＋條件文案），條件直接讀 §1 第 6 點的既有規則，**不新增存檔欄位、不另存「已看過」旗標**（沿用 EARLY-FLOW 的「教學偏好不入存檔」原則）。
- **Dock 層級**：建議「洞府＋經營」常駐；「修行」於第一個修行頁可用時出現；「遊歷」於九界／宗門／機緣任一可用時出現，出現時播短動畫＋紅點。**這與 `docs/12:39` 與 docs/07「固定四入口」衝突，需你同意修改**。
- 「新解鎖」紅點：只在**本次遊戲階段內**、且任務指向該頁時顯示，重載後由任務卷軸重新導引；若你要「永久只提示一次」則需存檔欄位（走版本＋故障復原＋測試，成本高，不建議）。
