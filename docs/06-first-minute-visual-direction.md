## 2. 現有概念如何收斂

「內景經脈 → 外景洞府 → 諸天九界」仍成立，但日常主介面以活的洞府為中心：頂部簡潔資訊、中段完整場景、底部一個當下目標及主要操作。工筆人物與五行圖譜放在內景分頁，適合功法與天賦的理解、配置，不必長時間佔據開局主畫面。

遠山、靈氣、建築燈火提供持續回饋；古金用於重要目標及航路，青玉用於穩定產出。細邊框與小印章支撐閱讀，保留場景空間。這次原型沿用繁中字型資產，實際標籤皆可選取、可修改。

| 介面層 | 初期看見 | 後期看見 | 穩定的操作習慣 |
| --- | --- | --- | --- |
| 頂部 | 境界、壽元、当前供給 | 選定界域與據點摘要 | 關鍵資料不超過兩行，詳細資源另開 |
| 世界場景 | 小屋、修士、藥圃與靈流 | 世界剪影、據點及聯繫 | 點物件開詳情；保留可認出的家 |
| 下方任務 | 引氣、建設、突破準備 | 法則差異與供給配置 | 一個主要動作、一個次要入口 |
| 底部導航 | 洞府、內景、九界預覽 | 同三個入口 | 隨時一鍵返回洞府 |

手機以直式閱讀為基線；桌面原型左邊是設計解說，右邊才是預期遊戲畫面。解說欄不會成為正式遊戲 HUD。正式數值使用穩定易讀字體，長篇工筆文字只出現在圖鑑等低頻頁面。

## 3. 第一分鐘的鉤子

核心橋段：**第一次引氣，熟悉的洞府縮為天外一點燈火；玩家記住遠方，再回來經營眼前。**

| 體驗時間目標 | 看到什麼 | 做什麼 | 留下什麼 |
| --- | --- | --- | --- |
| 0–10 秒 | 清晨小屋、修士、雲霧，遠天淡淡圓弧 | 看見唯一明確的「引氣入體」 | 世界可親近，當下目標可理解 |
| 10–25 秒 | 靈氣向修士匯聚，小屋燈火呼應 | 點一次即可啟動示範 | 明白修行會自行延續，不靠反覆點擊 |
| 25–40 秒 | 丹田圓紋對位天門圓環，鏡頭抽遠，家仍可辨識 | 觀看約 6–8 秒、可跳過的神識一瞥 | 看见尺度躍升與長期渴望 |
| 40–60 秒 | 九界圖、所選界域的独特景象與玩法一句話 | 可標記嚮往，也可直接返回 | 同時保留眼前建設與遠方目標 |
| 後續短登入 | 上次累積與一項可完成的建設 | 配置供給、準備突破 | 一次實際改變讓長期目標更可信 |

目前原型為快速評圖，在引氣後約 2.2 秒切換場景；其餘由玩家點選，沒有完整 6–8 秒鏡頭動畫或音訊。正式版只在第一次有意義的啟靈事件後提供演出，記錄已看狀態，圖鑑可重播。瀏覽器分頁重啟不應強制重看。

這是 v2 新增的敘事鉤子，觸發事件需映射到舊版新手流程。它不直接給高境界能力、不提前安排雷劫、不假裝玩家已經飛升；舊作金丹起渡劫的規則保留。開局可看見九界，不代表第一分鐘到達九界。

## 4. 三層目標同時存在

- 眼前：建立供給、處理容量、準備當前境界突破。
- 中期：突破、功法、輪迴與傳承，讓下一段修行有新的配置選擇。
- 遠期：建立第一個跨界據點，最終塑造自己的洞天。

九界圖允許查看遠景與標記目標。標記不消耗資源、不給倍率，也不解鎖通行。通行條件在跨界玩法验证後定案，不在概念圖先捏造一條境界對九界的升級表。十二修行境界與九界分類維持獨立。

為保留探索感，開局所有界域可知道名稱與主要差異，深層世界及完整事件仍未知。太初界只呈現「有限預算創界」的願景，不能展示為目前已存在的可玩功能。

## 5. 後期如何保持遊戲性

九界是一張依界域法則分類的導航圖，實際位置仍按洞府／區域／世界／星域／宇宙分層。世界的生成數量與九種法則分類不同；九個圖鑑節點不代表宇宙只有九顆星球。

後期原型用「人界＋靈界兩處據點」示意：人界仍是修煉與供給根基，靈界有靈潮帶來的配置取捨。點靈界看法則與供給，再回洞府理解它的作用。現在這些為詳情示意，沒有真正調度或產出結算。

其餘界域沿用既有提案：妖界有限靈獸協作、冥界當世與傳承交換、魔界維持成本、仙界有限樞紐、神界有限法則槽、混沌界可預覽規則組合、太初界有限預算創界。宏大世界的價值來自配置差異與自己的據點歷史，而不只換背景、堆倍率。

## 6. 驚豔效果如何落地到 Godot

| 效果 | 原型已呈現 | 正式 Godot 工作 |
| --- | --- | --- |
| 工筆山河與天門尺度 | 三聯背景、相同小屋呼應 | 製作獨立遠山、雲霧、中景、建築、修士與遮罩；圖集不能直接代替分層資產 |
| 自行運轉感 | CSS 靈氣環、稀疏粒子與霧層 | CanvasItem／少量粒子，依真實生產狀態調節，避免一資源一粒子 |
| 天外一瞥 | 背景淡換與小幅縮放 | 抽遠、圓形遮罩對位、天門展開、聲音層次；先做 6–8 秒樣片 |
| 九界可讀導航 | 真實 HTML 節點、航路、詳情抽屜 | Control 節點與曲線；每界先一個符號與代表剪影，主次明確 |
| 安靜模式 | 減少動態按鈕及系統偏好 | 關閉浮動及鏡頭震動仍能辨識全部狀態，演出可跳過 |

本次瀏覽器樣例沒有驗證 Godot 手機幀率、GPU 負載、完整分層視差、音訊或離線模擬。下一個美術探針應把「一座洞府＋天門一瞥＋可返回」移植到獨立 Godot 場景，再測單執行緒 Compatibility Web 的實際效果。最先確認小屋好看、字體可讀、第一個尺度切換成立；其餘八界先有剪影，不提前製作九套完整場景。

## 7. 評圖與驗收

驗收提問：玩家看完一分鐘後，能否說出「我的起點在哪裡」「現在做什麼」「未來想去哪裡」，以及「看見不等於已到達」？用 5 位新玩家測試，至少 4 位能無提示回答前三項，作為下一輪體驗目標。這是待執行測試，非已取得數據。

本次已用瀏覽器操作驗證：引氣後自動轉場、九界九個詳情入口、標記妖界後仍顯示未解鎖。原型獨立於 Godot 存檔，展示進度不持久化。後續結果見同目錄驗收紀錄。
