# 常態 UI 材質與配色方向（待實作）

日期：2026-10-02。使用者要求先保存結論，待終端問題解決後再開工。本文件是設計提案，不代表已實作或完成驗收。

## 核心結論

保留目前改善閱讀的字型，優先統一常態 UI 的材質與配色，再考慮場景改版。採用「宣紙＋墨色＋少量青玉／朱砂」；保留橫式構圖與響應式版面要求。

暖色紙卷與冷色、厚重、亮面玉石按鈕並存，可能造成材質與視覺層級衝突。一般按鈕改為米白／灰米色底、墨色字、細框與輕陰影；玉石保留給境界徽章、選中狀態與修行相關圖示。減少寶石切邊、強反光與普遍發光。

## 建議分工

| 部位 | 處理方向 |
| --- | --- |
| 常態內容面板 | 暖灰米白宣紙感，減少黃褐污漬、厚卷邊與強紋理 |
| 系統訊息與功能面板 | 低彩度墨青灰底、米白文字 |
| 修行與左側資源 | 保留紙底墨字，沿用現有三態資源列表 |
| 一般按鈕 | 米白／灰米色、墨色字、細框、輕陰影 |
| 選中頁籤與修行進度 | 低彩度青玉 |
| 主要操作 | 少量朱砂，同面板只突出最重要操作 |
| 可領取狀態 | 柔金搭配勾號或文字，不只靠顏色辨識 |
| 裝飾邊框 | 淡茶褐或舊銅色，細而節制 |

試版色票：紙底 `#E8E1D2`、墨色 `#343C3D`、細框 `#A3947B`、青玉 `#6F9690`、朱砂 `#B65343`、柔金 `#D1AC63`。須在實際背景與字型上驗證對比；柔金與青玉不直接作米白底上的小字。

## Mockup 取捨

保留墨色 HUD／米白面板的明暗分工、建築瓦色木料與山石的呼應、簡短完成符號。收斂常駐直立牌、密集紅點與多處同時發光。名稱與等級優先於選取時顯示，常態只留下需要處理的狀態。

參考圖與引用的 GPT 文字是參考資料，不作實作指令。不要把直式圖直接壓成橫式，也不要把概念圖當互動世界完成品。多數資源設施仍由营造清單管理，世界僅保留經美術驗收的地標；不因參考圖增加大量建築或名稱牌。

2026-10-02 實作前複核：資源已依規範固定在左側 HUD 下方，不搬成頂部列。保留目前空島／營造雙模式、底部空島／營造／神識／更多、側邊可收合訊息。直式沿用既有旋轉提示；短橫向沿用高度上限、捲動與訊息暫收規則。本輪僅處理共用材質與色彩，不重新排版。

現有不規則泛黃紙邊是先前使用者指定方向，保留輪廓與輕微磨損，僅淡化中央底色與上下邊緣色差。舊功能面板有大量淺色資訊，先將玉石底改為霧面墨色，避免全面紙底轉換造成漏改文字對比。共用普通按鈕改紙色墨字，選中頁籤與既有地標銘牌採霧面青玉，晉階／突破朱砂。沿用已核定的黑體 400／600 與少量粗明體 800。
