# ECON-R1-D2：後段構件與 Era5–6

範圍承接 D1；本檔只記契約、取捨與證據界線。完成判定、實際命令與結果統一見 [開發狀態](../development-status.md#econ-r1-d2)。

## 獨立入口與版本

`EconomySlice.create_frontier()` 明確組裝 R01–R14 及兩種構件，外層 rules/economy 升為 `econ-r1-rules-4`／`econ-r1-economy-4`，content 增 `+econ-r1-d2-1`；schema／研究格式維持1，研究 catalog 另驗 SHA。`create()` 保留 C，`create_late()` 保留 D1；不切換正式 launcher、不自動升降版、不改舊玩家進度。

結構式 core codec 沒有 GameContent 參數，因此以兩個新版專用資源槽識別 D2 的配方／工時／所有權／預留驗證；完整應用入口另檢查上述版本與 checksum。原版狀態沒有這兩個槽，仍使用原始供給表。這不是讓玩家以庫存數量解鎖工藝：實際命令／manufacturing view 仍檢查當世 research。

保存沿 B：先歸檔來源原文、候選快照、雙槽讀回、相同 bytes 重試；拒寫不安裝 live candidate、不重扣製造材料、不重播完工。新配方在製工作可原樣保存／重載，工時凍結，升設備只影響下一批。

## 新構件的取捨

C 已刪除與既有陣芯重疊的靈紋構件。D2 保留兩種跨線整合品：

| 構件 | 研究／Era、直接成本、基礎工時 | 已實作用途與經濟效果 |
| --- | --- | --- |
| 秘銀陣匣 `mithril_matrix` | R11／Era4；陣芯2＋精鐵5＋秘銀2；40秒；cap60 | 秘銀研習儀2件：祖島木／下石各+4基礎產率；陣匣儲運庫3件：木容量+500、中石容量+5000；R14試製2件；太虛陣樞每件2件 |
| 太虛陣樞 `void_array` | R14／Era6；陣匣2＋符咒4＋上石10＋虛空精華5；90秒；cap30 | 太虛凝石坊2件：凝石三配方增加0.3工時減免來源，經 work_time sum-then-DR；另加靈力100／下石30基礎產率。太虛採集儀2件：太虛島本地虛空採集倍率×1.5，另加金錢50基礎產率 |

上述設施皆當世一次性工程，不以 Era7 未實作內容充當第二用途。研習儀的本輪效果是材料供給，沒有宣稱它縮短研究秒數。陣匣整合前階木／銅加工與分階金屬；陣樞整合陣匣、符咒、凝石與虛空採集。二者皆實付祖島材料、祖島入庫、共享原有 home 產線；沒有獨立免費構件庫或動畫發獎。

首個陣匣的配方／研究不消耗陣匣；R14只消耗已可取得的陣匣與太虛原料，不消耗陣樞。首個必要工程不超過 cap，首購陣匣需求最大3／60、陣樞2／30。陣匣儲運庫的容量同時接入權威生產與製造／運輸上限。擴充版中石沿既有Production資源上限1,000,000，工程後基礎上限1,005,000；木由150增至650。配方表的10,000不是擴充版權威庫容，15,000是本次三層備料目標，不能誤稱倉庫上限。

## 排程與量測

D1交接曾把元嬰累計壽限誤寫為42,000秒；現行Era1–4為80＋120＋540＋350祀，正式函式回傳65,400秒，因此D1末態41,497秒實際餘裕23,903秒。這是文件推算更正，沒有更改壽元資料或規則。Era5累計101,400秒，Era6為158,400秒。

散修控制器只送 `EconomyProfile` 正式命令並推進權威秒數。每次付款前記錄容量，材料在祖島不足就製造／等實際回運。R11前先備元嬰剩餘升層物料，再於研習等待中按已滿足的時間／庫存升層，避免研究等待積累的修行時間一直耗在同一層。R14前亦以已賺得Era6入口預備三層帳單並合併R14試製需求，避免上石製作吃掉升層中石；資源均先核對權威容量。一般ladder自己持有升層報價及付款，不在其備料途中插入另一個升層。這是測量策略，沒有新增自動升層產品功能。

- `econ_r1_frontier_runner.gd`：日常短契約；`DAO_ECON_D2_EARNED=1` 明確啟用空白 seed1 散修長分析。每境 checkpoint／末態存於隔離 `.test-output/`；`DAO_ECON_D2_RESUME` 僅透過真實 profile decoder 接回同版 checkpoint，不改其庫存、Era或研究。
- `DAO_ECON_D2_REBUILD=<真實Era6 checkpoint>`：同版第一世自然壽盡、正式輪迴、第二世重建至Era3十層，檢查R01–R07相同材料／縮短工時、研究與設備重置及零構件繼承。不冒稱第二世Era6。
- `econ_r1_comparison_runner.gd`：明示資助 Era6 fixture，散修與五宗各60權威秒；各宗同5000貢獻預算，正式付費學A3＋B3（合計950貢獻，不把未花預算當實付），比較修速、金屬、藥材、壽元、容量與凝石／陣芯工時；產量包含地方、祖島與在途總數，不把已出航貨物當少產。10秒凝石配方受整秒向上取整，A3＋B3天劍的本次工時仍10秒；20秒陣芯則可量到19秒。另做壽盡邊界／14項研究重研報價契約。這是既有專法敏感度，不是五宗從新檔取得貢獻的全流程。

在線／分數秒分段／UTC均比較所有state與research欄位。只有 life_ledger.current.accounts.rows 的 closing 觀測數字按既有1e-6付款精度正規化，因重載可產生約1e-13的JSON浮點尾差；實際庫存、研究、revision與工作保持精確比較。原始各分支完整快照保留在boundary-parity.json，不刪觀測、不擴存檔限額。

這些證據不等於自然時間滑鼠通關、全seed最佳策略、五宗全程投資回收或80–160h平衡定稿。UI／Chrome屬E，候選包與整批唯一L3屬F。
