# Dao2 主旋律第二稿｜玉山餘響（M2-D-A1）

日期：2026-09-28。狀態：六段可試聽的原創草稿，待使用者以主旋律聽感驗收。

## 為何重寫

使用者試聽第一稿後指出：音色、低音與氛圍尚可，但主旋律不夠協調。第一稿採 D Dorian、密集的四小節旋律，且有較大的跳進；這是作曲判斷上的問題，不能只靠替換音色處理。因此第二稿先做不靠鋪底的主旋律獨奏，再讓五個場景版本使用同一旋律。

DAO1 參考音檔：`E:\Python\test1\dist\Whispers_of_the_Jade_Mountain.mp3`，30.772 秒，44.1 kHz 立體聲，SHA-256 `3B00CA1D937DBF18B04A1122CA8127F1C5CB75C928C5761B3C2A7E4311DBD982`。舊專案與原 MP3 均保持唯讀。由於本工作階段不能直接聆聽音訊輸入，以下分析取自頻譜與音高候選，**不是人工逐音轉譜**：C、E♭、F、G、B♭、A♭ 在音級能量中突出；約 0.6–2.5 秒的高音持續句較常見，整體比第一稿有更多呼吸。高音候選可能包含伴奏泛音，因此只拿調性、時值與分句密度作參考，沒有搬用 DAO1 的旋律片段。

## 新主旋律

維持 4/4、64 BPM、16 小節 60 秒的變體切換網格。旋律與和聲改為 C 小調語彙，以 C、E♭、F、G、B♭ 為主要音，D 是過渡／九度音。主旋律只有 12 個音分布於四小節，起句先留半拍：

| 小節 | 音名與拍值 | 意思 |
| --- | --- | --- |
| 1 | 休止(0.5) E♭4(1.5) G4(1) F4(1) | 起念；先呼吸，往上看後微回頭 |
| 2 | E♭4(1) C4(2) 休止(1) | 落在人間，留出回答的空間 |
| 3 | G4(1) B♭4(1) C5(2) | 神識伸向遠處，唯一的高點 |
| 4 | B♭4(1) G4(1) F4(1) D4(1) | 逐步回落；下一輪 E♭ 給出柔和解答 |

四小節和聲：**Cm → A♭maj7 → E♭6/G → Gm7**。第一小節 F 是短暫的懸念，其餘主要長音落在當下和弦；第 16 小節統一收成 C–G–D 開放音程，讓下一版從 Cm 進入。第一稿的 D Dorian 旋律與和聲保留在 `assets/audio/theme_prototypes/` 根目錄，作為對照，不覆寫。

## 試聽順序

先聽 `v2/00_theme_lead.ogg`：只有較乾的鋼琴感主旋律，確認四小節是否能記住、能哼出、有沒有生硬音程。再聽 `v2/01_abode.ogg` 確認主旋律放回洞府低音與撥弦後是否仍清楚。其他四版維持原場景功能：靜修減少句子、突破提高第三輪音域、輪迴保留骨幹音、宇宙降低八度。它們沿用原先的空間層次與合成方法，重點是讓新的旋律成為共同身份。

六版各為 60 秒，均提供 Ogg 試聽與分軌 MIDI；建置入口仍為 `python tools/compose_theme_prototypes.py`。目前是合成草稿，正式樂器、混音、遊戲內循環與跨版切換需在主旋律方向通過試聽後製作。最終成品不得取樣或重製 DAO1 音檔，資產與音源授權另記錄。

技術檢查：六個 Ogg 均完整解碼並由 `ffprobe` 確認 60.000 秒；六個 MIDI 的格式、軌道數和資料區塊長度一致。Ogg 首尾單點跳幅為 0.0001–0.0032（滿幅為 1），只能篩除顯著爆音，仍須以耳朵判斷旋律與跨版銜接。
