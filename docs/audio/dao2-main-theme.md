# 洞府主題旋律與五種變體（M2-D-A1）

日期：2026-09-28。此頁為第一稿，使用者試聽後指出主旋律不夠協調；現行試聽與旋律規劃請看[第二稿](dao2-main-theme-v2.md)。原 Ogg 與 MIDI 保留於 `assets/audio/theme_prototypes/` 根目錄供比較。

## 參考與創作界線

使用者提供的[影片](https://www.youtube.com/watch?v=aN53Va60sY8)以《星際效應》的〈Cornfield Chase〉討論日常情感如何連到宏大宇宙，以及音符、音色與敘事編排的作用。此處參考的是「一段親近的旋律隨場景擴大」的敘事方法。影片頁面的標題與說明可核對；本輪沒有直接取得影片音訊或逐字稿，因此不聲稱完成逐秒配樂分析。下列旋律、和聲、節奏及合成音訊均在 Dao2 專案內原創製作，沒有取樣或轉錄電影配樂。

情緒主線：**凡人的一口氣 → 對生命的提問 → 神識伸向遠方 → 回到自己的洞府**。即使畫面進入九界，音樂仍須保留一點人的溫度。

## 共用樂譜契約

| 項目 | 設定 |
| --- | --- |
| 拍號／速度 | 4/4、64 BPM；16 小節恰好 60 秒 |
| 調式 | D Dorian（D、E、F、G、A、B、C）；B 自然音帶來一線希望 |
| 四小節和聲 | Dm(add9) → Cmaj7 → G(add9)/B → Dm(add9) |
| 主題結構 | 先小幅上行，再用 B–A–G 回望；第三小節觸及高音 E，第四小節落回 D |
| 第 16 小節 | 所有版本共用 D–A–E 開放音程，撤去主旋律與明顯節奏，作為下一版的接點 |

主旋律音名與拍值如下；每列一小節，數字為拍數：

| 小節 | 旋律 |
| --- | --- |
| 1 | D4(1.5) F4(0.5) G4(1) A4(1) |
| 2 | C5(1) B4(0.5) A4(0.5) G4(2) |
| 3 | F4(1) A4(1) E5(1.5) D5(0.5) |
| 4 | C5(1) A4(1) E4(1) D4(1) |

全曲採四次四小節循環：1–4 小節提出線索、5–8 小節明確述說、9–12 小節變化、13–15 小節收束，16 小節留下共同接點。變體可刪音、改八度與重新配器，必須維持可辨識的前四音輪廓與共用節拍。

## 60 秒變體

| 檔名 | 場景與情緒 | 草稿音色 | 變形方式 |
| --- | --- | --- | --- |
| `01_abode` | 洞府、建設與回家；溫暖、能長聽 | 簫感主奏、柔和弦、輕撥弦 | 主旋律完整，氣息與空拍優先 |
| `02_meditation` | 靜修、內觀；專注、時間變慢 | 清亮鈴音、空氣墊音、稀疏撥弦 | 隔段出現旋律，讓留白成為節奏 |
| `03_breakthrough` | 升境前後；克制地擴張 | 管風琴感主奏、低脈衝、厚和弦 | 第三輪升高一個八度；脈衝提供推力但不壓過遊戲資訊 |
| `04_reincarnation` | 壽盡與新生；懷念後仍向前 | 低氣息主奏、柔軟墊音 | 部分旋律只留下骨幹音，完整句在下一輪回來 |
| `05_cosmos` | 九界遠景；遼闊而保有人味 | 低音域管風琴感、開放墊音 | 主旋律降低八度，拉長音尾，空間感取代節奏密度 |

目前音色均由本地 Python 合成；「簫感」「管風琴感」只描述草稿功能，不代表真實樂器錄音。正式製作可替換為高品質音源，保持同一 MIDI 音符與結構。

## 循環與跨版本切換

1. 五版都使用相同 64 BPM、D 根音與 16 小節長度。每版音訊恰好 60 秒，可獨立從頭循環。
2. 若場景發生變化，於最近的第 16 小節（56.25 秒）啟動下一版第 1 小節，做一小節、3.75 秒等功率交叉淡入淡出。兩邊此時都以 D/A 為核心，能避免突然換調。場景需要即時反應時，可先播放音效，音樂等到接點再變。
3. 同一版直接循環時從 60.00 秒返回 0.00 秒。合成草稿的延音以整段週期方式回繞；正式混音要把殘響尾音預捲到開頭，並檢查壓縮後的接點爆音與音量跳變。
4. 不把影片、事件或收益綁在音訊播放到某個時間點；音樂控制只讀取遊戲狀態，音訊關閉或切換不影響模擬。

## 交付檔案與製作下一步

- `assets/audio/theme_prototypes/*.ogg`：五個 24 kHz、單聲道、一分鐘的可聽草稿。可直接在播放器試聽；目前沒有接入遊戲，並已由 `export_presets.cfg` 排除 Web Release。
- 同名 `*.mid`：分軌 MIDI，主奏、和弦、撥奏各有獨立音色軌，可在 DAW 或其他工具換音色、重錄。
- 第一稿的 Ogg／MIDI 已保留供比較；目前 `tools/compose_theme_prototypes.py` 重建的是第二稿，第一稿不再由當前腳本重建。
- 定稿前須以實際遊戲音量試聽 01→02、02→03、03→04、04→05、05→01，以及每版自行循環；檢查接點、長時間聽感和手機喇叭。再輸出正式 48 kHz 立體聲 Ogg，記錄所用音源與授權。

這是作曲與編曲原型，尚未代表正式配樂或遊戲內切換功能完成。

技術檢查：五個 Ogg 均可完整解碼，`ffprobe` 顯示每段 60.000 秒；編碼後的單點首尾跳幅為 0.0004–0.0061（滿幅為 1）。此數字只能篩除明顯的接點爆音，仍需實際聆聽循環與跨版銜接。
