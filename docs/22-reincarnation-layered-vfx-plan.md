## 4. 動畫設計與初始調參

## 5. 豎排水墨字與Glow

文字內容首版沿六道意象「天人、人間、修羅、畜生、餓鬼、地獄」。每列由上往下排，字保持正立，不把橫排Label旋轉90°；每列作一個完整文字粒子上浮，個別字只作很小相位差。每批錯開出生，避免六列同時塞滿盤心。

字形選用具楷書／筆觸感的授權字型，再疊加低振幅紙纖維噪聲、筆畫缺墨與邊緣暈染。候選為[霞鶩文楷](https://github.com/lxgw/LxgwWenKai)及其上游列出的TC版本：上游標示OFL-1.1，但尚未下載或驗證本專案字形；需比較十二個用字樣張，確認筆觸足夠、繁體字形與字重一致。它是候選字型，不因名字含楷就宣稱已達濃墨毛筆效果。

Godot動態文字先以專用演出字型繪出乾淨字形mask，六組固定文字於初始化／尺寸檔位變更時快取，避免每幀重建SubViewport。保留文字字串為來源，不將字寫進場景背景或命盤圖片。效能與字型授權允許時可輸出專用字形atlas，必須保留可重現生成步驟。

每列採三層：清晰墨色／暖白字芯 → 局部暈墨邊 → 低透明度柔光。末段用噪聲侵蝕mask漸散，少量碎墨與光點延續上升。**粗描邊或加亮文字本身不等於Glow**；需要能看到輪廓外平滑衰減的光暈，同時讀得清筆畫。紙底以青墨芯＋淡金暈；深色演出以暖白筆芯＋青金柔光，避免亮度飽和吞字。

低特效模式保留靜態盤／蓮與可讀字，不轉盤、不移霧、不散墨，只作既有短淡入結算。頁面隱藏、切分頁與離開演出停止Shader時間推進、粒子與viewport更新；明確傳入 `effect_time`，不靠不可控制的全域TIME假定暫停。
