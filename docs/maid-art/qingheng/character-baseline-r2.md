# 青蘅 E：角色設定基準 R2

任務 `MAID-ART-BASELINE-R2`，2026-10-31。E畫風／造型已接受；本輪新設定圖、透明立繪與布局為待審稿。這份基準鎖定後續製圖的一致性，不代表仙侍規則已核定。

## 角色與辨識

- 青蘅，成年女性，外觀約25歲；溫柔、有主見的書卷型洞府仙侍。說話親近但不過度依附，會先問主人希望如何整理，再提出自己的辦法。
- 臉：柔和成年鵝蛋臉、藍色杏眼、小巧鼻唇、自然淺笑；保留E的眼距與頰線，不改成幼童比例。
- 髮：深海軍藍長髮、半挽高髻與細碎瀏海；白花、青玉葉、細金簪及垂鏈。主要輪廓是頭頂花簪、兩側長髮與層疊袖裙。
- 衣：青藍高領內身、合身深藍腰封、露肩與寬鬆白袖、白／淺藍多層長裙、竹葉紋、細金邊；青玉腰墜、藍繡鞋。成熟優雅尺度沿E。
- 道具：深藍書冊與毛筆；日常主立繪持書執筆，初遇可以雙手護書。道具換位不可造成髮簪、領型或衣飾任意改款。

配色指導值：髮 `#23345E`、髮亮部 `#536FAD`、瞳 `#5B9DDB`、衣深藍 `#294D7C`、淺藍 `#A8C6EA`、白絹 `#F3F2EE`、古金 `#B79A61`、玉 `#A5C5BB`。這是製圖比對用色，不要求有光照的圖每像素相同。

## 性格與初遇文案候選

初遇章名「雨過書未濕」。雨夜走到新落成洞府的簷下，她先護住書冊，確認沒有打擾，再請求借一處乾燥的桌面。

> 「冒昧叨擾。這一路只顧護著書，倒忘了替自己避雨……可容我借一角簷下，理好這幾頁？」

兩句玩家回應候選：「先進來避雨吧。」「書裡記著甚麼？」均導向相識，不標示好感加減、獎勵或招募結果。此輪只驗敘事氣氛；出場條件、章節選擇與保存另待規則設計。

## 版型與Godot接入對照

- 角色頁：沿經營工作台canonical route，寬式主立繪約46%工作區、人物介紹在另側。範例僅「人物」可讀；職掌／羈絆未核定前不顯示假數值與可用命令。共用GameTab、思源黑體與唯一CloseSeal必須由正式元件接線。
- 緊湊橫式：立繪縮為可開看圖的預覽；人物正文在單區內捲，頁首和關閉固定。看圖採完整contain，避免臉部與裙襬被裁掉；關閉回原頁。
- 初遇：CG上部保留清楚的臉與書冊，底部獨立紙面敘事／選項；字級18、動作至少44px。不把選項烘焙進CG；短式縮短台詞首屏顯示，全文可內捲。
- 寬式門檻沿共用殼：寬至少960、高至少500、比例至少1.45；其他橫式用緊湊。直式顯示既有旋轉提示。HTML只是可審閱工具，不構成正式Godot命中、Web匯出或玩家流程驗收。
- 正式接入時使用錨點、HBox／VBoxContainer、ScrollContainer與TextureRect的contain配適；背景不攔截輸入。圖片失敗應顯示可閱讀人物與關閉入口，不能阻塞保存保護。
