## 驗收步驟

### 階段 1：Era 1 開局（0–5 分鐘）

1. **首次啟動**：
   - [ ] 看到「神識一瞥」九界預覽（可跳過）
   - [ ] 返回自己的洞府，看到茅屋
   - [ ] Console 無 warn/error

2. **T1 建設**：
   - [ ] 點擊「營造」→ 建茅屋（花費 100 靈氣）
   - [ ] 觀察飛劍與靈氣流動反映產率
   - [ ] 等待靈氣累積，手動點擊「修行」按鈕

3. **首次升境（練氣→築基）**：
   - [ ] 靈氣達門檻（約 200）→ 觸發突破演出
   - [ ] 觀察金環／雷電特效（FX2）
   - [ ] 突破後看到木屋、林場、採石場解鎖

**預期耗時**：3–5 分鐘（真實等待，不加速）

---

### 階段 2：Era 2 擴張（5–15 分鐘）

4. **容量升級**：
   - [ ] 建「儲靈倉儲」（+100 容量／級）
   - [ ] 建「築基靈池」（+1000 容量／級，最高 3 級）
   - [ ] 確認 HUD 顯示容量上限

5. **遠島開拓**：
   - [ ] 點擊「經營」→「三島」→ 看到青木島／玄礦島
   - [ ] 青木島開拓（花費 wood/stone）→ 看到林地標誌
   - [ ] 玄礦島開拓 → 看到礦坑標誌
   - [ ] 觀察航線動畫（原料回運）

6. **T2 加工**：
   - [ ] 祖島建「熔爐」（wood/stone）→ 加工 bronze_ore → bronze_essence
   - [ ] 點擊「開始加工」→ 觀察 10 秒倒數
   - [ ] 成品入庫，確認庫存變化

**預期耗時**：5–10 分鐘

---

### 階段 3：Era 3 突破（15–30 分鐘）

7. **容量達標**：
   - [ ] 築基靈池 2 級 + 儲靈倉儲 2 級 + 基礎 100 = 2300 容量
   - [ ] 靈氣累積至 2000 → 滿足 Era 3 突破條件

8. **金丹突破**：
   - [ ] 觸發突破演出（更強烈特效）
   - [ ] 突破後看到「丹霞島」按鈕
   - [ ] 點擊「經營」→ 看到丹霞島（赤色砂岩地貌）

**預期耗時**：10–15 分鐘

---

### 階段 4：丹霞加工閉環（30–60 分鐘）

9. **丹霞開拓**：
   - [ ] 點擊丹霞島 → 看到藥坊地標（紅字赤岩、低草地）
   - [ ] 開拓丹霞（花費 wood20/stone10）→ 藥坊啟用

10. **丹液加工**：
    - [ ] 點擊丹霞管理 → 開始丹液加工（消耗百年草 + 共用靈力費）
    - [ ] 觀察「操作完成，已保存」提示
    - [ ] 觀察貨運動畫：丹液回運祖島

11. **T3 陣芯**：
    - [ ] 祖島建「陣法工坊」（需 bronze_essence）
    - [ ] 加工 formation_core（需丹液 + bronze_essence）
    - [ ] 確認成品入庫

12. **修行扣料**：
    - [ ] 點擊「修行」→ 金丹層級提升
    - [ ] 觀察 talisman 消耗
    - [ ] 確認修行時間推進

**預期耗時**：20–30 分鐘（丹液加工約 20 秒／次）

---

### 階段 5：保存與重載驗證

13. **重載測試**：
    - [ ] 在丹霞加工進行中按 F5 重載
    - [ ] 確認離線摘要正確（加工剩餘時間）
    - [ ] 重載後丹霞島仍開放、藥坊仍在
    - [ ] 庫存與修行進度完整保留

14. **第二次重載**：
    - [ ] 等待 60 秒自然遊玩
    - [ ] 再次重載
    - [ ] 確認無重複獎勵、無資料丟失
