# RES1-UI1-C 實機與人工驗收單

2026-10-09（Asia/Taipei）。**待驗**：使用者本輪確認「目前無實體裝置，保留實機待驗」。桌面縮小 viewport 不代替實體觸控、手機 GPU 或 DPR2–3。

使用與 UI1-C 驗收報告相同版本的正常 Web 包，建立裝置可存取的獨立測試 origin。現有 4293／4294 僅綁本機 loopback，手機不能直接使用電腦的 `127.0.0.1`；本輪未改防火牆、公開部署或開放 LAN。不要使用 4175 玩家存檔。先記錄包 SHA256、手機型號、OS／瀏覽器版本、CSS viewport、DPR、刷新率及時間。

| 步驟 | 驗收結果必須記錄 |
| --- | --- |
| 直式進入，再轉橫式；反覆切方向三次 | 旋轉提示可讀且阻擋底層玩法；回橫式後保持原製造／運輸詳情，無重複命令 |
| 在世界安全區單指平移、雙指縮放，回到祖島 | 點擊／拖曳／縮放互不誤觸；可回原視角，沒有卡住的手指狀態 |
| 分別開空島、製造、運輸；捲到最後配方／航線 | 固定返回與四主入口可達；內容在 Godot 內捲動；按住、滑出、放開、取消不觸发世界點選 |

| 以第二種瀏覽器重做輸入／保存／重載 | 瀏覽器名稱版本及獨立 origin 明確；存檔讀取錯誤不得當成空白新檔 |

另由使用者確認：正常自然時間空白開局 → 築基啟用 → 開拓／靈材／銅精 → 金丹丹霞 → 祖島合成／消耗，能理解擴產、加工與運力的選擇；接受操作簡化、文字可讀性、美術與節奏。自動命令／模擬秒、已賺得 fixture 和代理滑鼠驗收均不代替這項接受。
