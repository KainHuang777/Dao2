## 待執行：實機觸控操作單

本節是 M2-D 日後實測用程序，尚未構成通過證據。手機裝置模擬只能輔助版型檢查，不能取代實機觸控、瀏覽器手勢或 GPU／效能結果。每次至少以一台實體手機的直式與橫式各跑一次；記錄裝置型號、OS、瀏覽器／版本、完整 origin、CSS viewport、DPR、瀏覽器縮放、低特效設定和 build／commit，並保留截圖或短錄影。

測試前以 HTTP 開啟同一份 Web build；手機須以區網 IP 連入，不可輸入 `127.0.0.1`。IndexedDB 的獨立落盤操作見 [M1-C 驗收紀錄](m1-c.md#待執行瀏覽器-indexeddb-實測程序)；本節只驗證輸入、版型與核心正流程的觸控可用性。

| --- | --- | --- | --- |
| T-01 主要 UI 點擊 | 左側資源依次切換「關閉／數量／完整」，以獨立採集鈕採集金錢；點底部「營造」開清單，建茅屋、升級、點列展開成本及開詳情，再點「空島」返回 | 每一觸碰只送出一次正確命令；資源滿倉變色、完整值可讀，建築成本只在展開後顯示；HUD 與訊息不被遮擋，沒有不可達按鈕 | 直式／橫式各一份畫面或錄影 |
