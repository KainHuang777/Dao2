## 分頁與單選篩選

- 統一使用目前資源「關閉／數量／完整」三態的樣式：未選中為紙面深墨文字；選中為霧青玉底、淺色文字與素材中的細金色底線。Hover／按下沿相同色系，不能另創朱砂選中、菱形印記、金色藥丸或深色未選中塊。
- 功能頁分頁用 `GameTab`；分段篩選用 `SegmentChips`；現有資源三態、建築分類、製造分類及島嶼單選用 `UiMaterial.mark_paper_tab()`。共用樣式集中於這個函式，修一頁不複製另一份配色。底部四主入口沿用獨立 Dock；啟停、提交等動作不冒充單選分頁。
- 分頁選中只表示現在正在閱讀的頁面，不表示已解鎖。可用項目排前；近期待開放項目排後、灰化並直接標示「未開」；遠期功能隱藏且不佔空間。兩組內保持 canonical 順序。解鎖後即時更新並重排，不重建按鈕、不發獎、不新增保存欄位。
- 未開放狀態不能依賴 hover TIP；頁首分頁不顯示開放 TIP。可保留點入唯讀條件頁，頁內清楚列條件且原命令禁用。明訂隱藏的入口也須攔住情境捷徑；記憶頁無法進入時回退同群組可用頁。

## 字型與閱讀

- 正式介面統一使用思源黑體／`UiTypography.BASE_FONT`。正文、按鈕與分頁用 `body_font()`（400），標題／重點以同家族 600 字重區分；`chapter_font()` 也使用同一黑體家族。保留舊明體資產不代表可在新頁直接使用。
- 不在單頁直接 preload 字型或用明體製造另一套風格。遊戲文字由 Godot 獨立渲染，不烘焙到背景／資產。紙底深墨、青玉底淺字；禁用仍可讀，不用整面降透明度隱藏成本資訊。
- 字級與響應式閱讀規則沿 [07 響應式規格](07-responsive-ui-web-spec.md)，字型统一不授權縮小手機文字或命中區。

## 關閉與返回

- 頁首關閉使用共用 `CloseSeal`：至少44×44邏輯像素命中、紙面深墨叉號、常態透明背景；hover／按下只有淡墨色回饋。禁止常態黑色圓角底或厚重黑印。
- 關閉固定在頁首，不隨內容捲動；文字「返回」動作沿共用紙面按鈕，保持可辨識。裝飾不攔截輸入，關閉後恢復群組／資源與相機原有契約。
