# UI／UX 共用規範

2026-10-11 使用者核定，UIX-R3-F2。這是目前正式介面的共用依據；優先於歷史概念稿、R3-F1 明體墨字／朱砂小印、舊分頁黑體／明體混用與黑底關閉印。單頁修改必須沿用共用元件，當次使用者要求仍最高優先。

## 分頁與單選篩選

- 統一使用目前資源「關閉／數量／完整」三態的樣式：未選中為紙面深墨文字；選中為霧青玉底、淺色文字與素材中的細金色底線。Hover／按下沿相同色系，不能另創朱砂選中、菱形印記、金色藥丸或深色未選中塊。
- 功能頁分頁用 `GameTab`；分段篩選用 `SegmentChips`；現有資源三態、建築分類、製造分類及島嶼單選用 `UiMaterial.mark_paper_tab()`。共用樣式集中於這個函式，修一頁不複製另一份配色。底部四主入口沿用獨立 Dock；啟停、提交等動作不冒充單選分頁。
- 分頁選中只表示現在正在閱讀的頁面，不表示已解鎖。可用項目排前；近期待開放項目排後、灰化並直接標示「未開」；遠期功能隱藏且不佔空間。兩組內保持 canonical 順序。解鎖後即時更新並重排，不重建按鈕、不發獎、不新增保存欄位。
- 未開放狀態不能依賴 hover TIP；頁首分頁不顯示開放 TIP。可保留點入唯讀條件頁，頁內清楚列條件且原命令禁用。明訂隱藏的入口也須攔住情境捷徑；記憶頁無法進入時回退同群組可用頁。

## 字型與閱讀

- 正式介面統一使用思源黑體／`UiTypography.BASE_FONT`。正文、按鈕與分頁用 `body_font()`（400），標題／重點以同家族 600 字重區分；`chapter_font()` 也使用同一黑體家族。保留舊明體資產不代表可在新頁直接使用。
- 不在單頁直接 preload 字型或用明體製造另一套風格。遊戲文字由 Godot 獨立渲染，不烘焙到背景／資產。紙底深墨、青玉底淺字；禁用仍可讀，不用整面降透明度隱藏成本資訊。
- 字級與響應式閱讀規則沿 [07 響應式規格](07-responsive-ui-web-spec.md)，字型统一不授權縮小手機文字或命中區。

## 關閉與返回

- 頁首關閉使用共用 `CloseSeal`：至少44×44邏輯像素命中、紙面深墨叉號、常態透明背景；hover／按下只有淡墨色回饋。禁止常態黑色圓角底或厚重黑印。
- 關閉固定在頁首，不隨內容捲動；文字「返回」動作沿共用紙面按鈕，保持可辨識。裝飾不攔截輸入，關閉後恢復群組／資源與相機原有契約。

## 開放門檻與情境入口

| 內容 | 呈現門檻 | 資格與操作 |
| --- | --- | --- |
| 洞府建築、煉丹、成就 | Era1可見 | 煉丹保留練氣期原配方與服用；材料與設施仍由核心驗證 |
| 空島、集中製造、運輸 | Era2築基期起可見；Era1隱藏 | Era1情境連結回經營建築；Era2先沿原啟用／開拓流程，尚未啟用或缺料仍不能操作 |
| 青木／玄礦島 | Era2 | 各島開拓、設施與成本由核心驗證 |
| 丹霞島 | Era3 | 不因空島管理頁可見就提前開拓 |
| 丹液製造入口 | Era2祖島；Era3預設丹霞島 | 對應已核定祖島配方及核心所有權；不得在築基期只指向尚未開放的丹霞島，阻斷五層後的材料供給 |
| 技能、靈獸、宗門等 | `FeatureUnlocks`依正式View判定 | 未開放標示／隱藏策略不取代Session命令資格 |

入口可見、頁面可閱讀、取得資格與操作成功是四個不同狀態。不為顯示一致而提前解鎖規則；不以UI禁用代替Session驗證。呈現門檻集中於 `FeatureUnlocks`，情境路由由 `FeatureNavigation` 保護。

## 版面、資料與後續修改

- 2026-10-11 UIX-R4-F2 使用者核定：營造簿採手繪建築雙欄卡片，材料圖示與庫存／需求位於同一卡框內，材料進度只繞建築縮圖，不另設進度條。操作按鈕縮窄，仍保留至少44px命中；材料不足、前置不足及滿階用較暗的按鈕，成本本身保持可讀與缺料朱紅。短橫式可暫收左側HUD／資源，使用完整抽屜寬度；原晉階／突破操作移至抽屜固定頁首，關閉後回原HUD。桌面主動開啟訊息時允許縮回單欄以避免重疊。此條覆蓋R4-F1常態單欄，不更動共用分頁與字型。

- 沿 Godot 錨點／容器與共用 Theme。固定頁首與關閉、內容內捲、短橫式適配；不以固定Web畫布、瀏覽器捲軸或裁切逃避版面。至少44px命中。直式旋轉提示沿07，不另建一份正式直式流程。
- 同時只開一個玩法頁；沿四主入口與 canonical route，不新增重複 More 入口。成本／庫存就地讀Session View，UI送命令而不改庫存。保存失敗須保留原錯誤與重試。
- 共用元件變更須核對資源三態、經營／修行／遊歷頁首，以及受影響分類；以 Era1／Era2／Era3核對隱藏、未開及可用狀態。驗證1280×720、844×390、800×360切頁／返回及命中，不把CLI当真實瀏覽器操作證據。
- 只改單一頁也須先讀本頁與07；若需新增另一種選中樣式或字體，先取得使用者明確方向並更新共用規範，再實作。不得以歷史草稿覆蓋目前核定通則。

本輪實作與限制見 [UIX-R3-F2驗收](verification/uix-r3-f2.md)。人工美術、實體觸控／高DPR與原C/D待驗狀態不因本規範提升。
