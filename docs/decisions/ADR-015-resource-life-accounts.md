# ADR-015：有界資源收支帳與帳目閱讀

日期：2026-10-22。任務 `LEDGER-1／REPORT-1B`，承接 [docs27](../27-life-report-and-decision-ux-integration-plan.md) §8／§9；不開展 REPORT-2 曲線／歷世比較。

## 口徑與掛點

資源帳涵蓋 `state.resources`（祖島／全域別名不重複）、各島 inventory、在途貨物及靈界的 spirit_crystal／azure_nectar。丹藥獨立數量（築基丹的 resources 權威庫存除外）、道心、道證、宗門貢獻、獸魂、BUFF／修煉時間不混為資源；保留原系統及 DECISION-1 收據。不同資源不可相加為總財富。

每列採 `期末 = 期初 + 實際收入 - 已付支出 + 有號調整`。從每個已通過資格檢查、即將提交的原始寫入觀測 Amount before／after；回傳同一個 after 物件，原加減、比較、容量與鏡像規則保持。命令前後淨差僅用於對帳，不充作分類流水。同一機緣先付20再得30列20支出與30收入；即時 Craft 的材料與成品亦分開觀測後，再沿原一次性寫入。沒有新 RNG 或收益命令。

分類固定為生產、採集、營造、修行、煉丹、機緣、法令、宗門、靈獸、成就、小景、研習、加工、移轉、靈界及調整。原 _put／ProcessingInventory 鏡像路徑只記一次；新增非零資源 entry 也記錄。靈界晶體生產與同 tick 靈液耗晶分列。暫不加入日／年區間、年度快照或通用交易引擎。

未入庫以有名義產出之掛點的正差記錄，獨立於實收，不再從收入扣一次。滿倉的 prepared 快取與離線跳算同樣累計嘗試產量；原經濟靜止快取保留。容量收縮所造成的負變動列調整，不能當一般消費。原機緣不套容量截斷，Amount 精度亦可能造成未入庫。靈界加工先預留容量、無輸出不耗料，沒有虛構未生產的產品或材料支出。

離島出發減本島庫存，同額增加在途；抵達減在途、增目的島。全域合併包含在途，移轉收支從收入／消耗排除；單島則保留轉入／轉出。島庫存觀測原序列化後的真實字串；移轉額讀原 cargo，不以目的庫存浮點差反推貨物。實際庫存差與 cargo 的精度差列有號調整，避免在途變負或全域灌大產出。從核心尚未移除的真實 trips 讀在途期初，舊檔／隔離 fixture 的直接注入差異明列調整。

## 數值與覆蓋

所有累計沿 AmountCompat。layer0 字串以完整 JSON 浮點精度保存，不重用會在接近整數時捨入的顯示格式；小量科學記號回到同一 layer0，避免僅因文字解析造成層級變化。其他層沿既有 Amount 支援邊界，沒有修改 AmountCompat 或承諾全量大數精確。

逐秒與批次浮點加法可在最後數位不同，帳目以 Amount.compare_to 對比；實際經濟／RNG／貨物／預留／時間游標仍沿既有精確快照檢查。名義量與入庫量在 Amount 比較精度內相等時，不把浮點殘屑累加成未入庫。`estimated_bytes` 是保守容量計數，不是資源數量，不能把其文字長度差誤報為收益差。測試另驗逐列等式與權威收據。

新遊戲／轉世後以實際初始或繼承資源列期初，覆蓋完整。舊生命首次真實寫入才新增 accounts，標示實際記錄開始年歲與部分覆蓋；讀舊 schema5 不補造歷史或修改狀態。沒有帳目時顯示未有紀錄，不能宣稱此前收入為0。直接 debug／fixture 改庫存與上次期末不同時列調整，不能當正常產出。部分帳只加總保留的列，不推斷缺漏為0。

## 版本、容量與復原

沿 schema5／LifeLedger version1，每世新增選填 `accounts` version1。最多48個 scope／resource 列，每世最多12KiB，包含在原當世64KiB／每封存世32KiB／最近9世／總352KiB內，沒有增加保存額度。只聚合固定分類，沒有逐 tick 事件陣列。新增列／欄與數字字串大小納入保守計數；超限整列略去，記錄 omitted 次數並改部分覆蓋。omitted 包括略去寫入與被淘汰列，並非互異資源總數。

轉世在原清空前封存；先沿原 DecisionReceipt 整筆淘汰政策，再於仍超32KiB時從後逐列略去帳目。里程碑／凍結小傳／九世順序保持。開始下一世時重建真實期初，靈界跨世持有不算新生產。讀 API 深複製指定世；一般 HUD View 不攜帶 archive。未知版本、欄位、分類、scope／ID、非法數值與超限資料拒絕，沿既有 checksum／兩代復原／只讀保護與重試；不吞錯成零、不跳過 checksum。

## 呈現

輪迴原閱讀區使用既有 GameTab「帳目」展開；共用黑體、OptionButton、固定收益／確認／CloseSeal與單一內捲保持。選單44px命中及行高；支援全域與單島／靈界／在途單資源。兩條相對量級橫條配完整數值、來源／用途列表及覆蓋說明；不以朱紅推斷支出好壞，不把未入庫單獨判為瓶頸。大數條只計安全有界比值，不將庫存全面轉 float；可讀數值為主。

保存拒寫後沿原保護頁閱讀剛封存的同份帳；重試只保存，沒有再次提交或發道果。1280×720、844×390、800×360桌面驗證；觸控／實機依目前政策延期，非當輪阻擋。完整結果與失敗保留見 [驗收](../verification/ledger-1.md)。
