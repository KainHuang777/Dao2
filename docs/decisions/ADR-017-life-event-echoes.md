# ADR-017：從已提交事實讀取事件回聲

日期：2026-10-23。任務：ATM-LIFE-C。承接 ADR-013～016；本輪不新增經濟效果或抽選事件。

## 決定

使用純函式 `LifeEcho.generate(life)`，在當世行跡、卷末與歷世的同一 `LifeReportView` 顯示最多三條已完成回聲。每條含原創文字、兩個來源ID、事件年歲及可讀標籤；沿「查記錄」閱讀前因。不新增分頁、通知、道德值、NPC關係或事件腳本引擎。

| ID／題名 | 前因 | 後續事實／文字界線 |
| --- | --- | --- |
| inscription／石壁之後 | 同世權威收據：enc_ancient_cave、option_index=1，且所選原文為「凝神參悟石壁心法殘篇」 | 年歲嚴格較晚的cultivation_leveled_up；只說曾參悟、後有晉階，不將晉階歸因於該次獎勵 |
| sect／山門回程 | joined_sect | 序號較後且年歲不倒退的expedition_claimed；完成但未領取不寫領回所得，不編任務人物、對話或宗門名稱 |
| beast／同行漸長 | 有instance的beast_acquired | 同instance、同subject且序號較後的beast_matured；不借另一隻靈獸的成熟補成一條人生 |

文字由本輪針對專案原創，來源為現有機緣內容及正式命令提交後的里程碑／收據；沒有引用研究遊戲的事件文稿，沒有新增圖形資產或字型來源。全文見 `src/domain/life_echo.gd`。

## 邊界

- 回聲為有限事實的閱讀投影，沒有額外發獎或機率。不從庫存、跨世最高境界、靈獸現狀猜過去。未完成、缺來源、舊檔缺個體ID、收據略去或選項文案已改時不拼接該鏈。
- 同一類只取第一條可證實完整鏈；重讀不累加、不消耗RNG。收據與里程碑沒有共同序號，故機緣與晉階同年歲時不猜先後；宗門／靈獸沿既有事件seq，容許同tick合法命令先後。
- 原始事實依既有64事件／8收據上限，這不是全人生回聲。當世來源淘汰後可能不再有可證實完整鏈；不另存第二份當世事件庫。舊封存沒有echoes就保持原文。
- 轉世沿原原子操作、清空前 `LifeReport.generate`，把回聲及兩個簡短來源一併凍結於既有 `frozen_text`。之後來源簿裁剪或內容更新均不重寫已凍結文字。凍結來源是當時事實摘錄，完整成本／實得仍讀原抉擇簿，不能用回聲代替帳目。
- `report-1a-2-echo`／`echo_version=1`，最多3條、回聲2800 bytes上限，沿原frozen_text 4096 bytes及每世32KiB／當世64KiB／九世352KiB。沒有新保存欄位、schema保持5；舊版讀取契約保持。非法／未知凍結回聲採既有「小傳未記錄」安全兜底，不執行任何內容。
- UI仍是唯讀View。沿文楷18px敘事、黑體16px來源、44px操作、單區內捲與固定收益／確認／保存重試；低特效不影響文字。
