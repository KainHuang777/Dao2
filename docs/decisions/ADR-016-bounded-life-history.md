# ADR-016：有界歷世觀測與重讀

日期：2026-10-22。REPORT-2 承接 [整合計畫](../27-life-report-and-decision-ux-integration-plan.md) §8／§9、ADR-013～015。使用者指定 REPORT-2；九世／352 KiB 與 F-C 字體決策沿用。

## 資料與版本

沿 schema5／LifeLedger v1，新增選填 `history` v1 與封存 `settlement`。缺欄位合法且不補造；本版新增的選填欄位不承諾舊引擎降版讀取。歷世 API 沿 `GameSession.get_life_record()` 深複製，僅在明確閱讀頁使用，不加入逐幀 HUD View。

`history={version,started_at,omitted,samples}`；每點 `{at,rows}`，每列 `scope:resource → [stock,capacity|null]`，Amount 保存完整字串。最多16點、每點12種資源、每世6 KiB，包含於原當世64 KiB／封存32 KiB／最近九世／總352 KiB。來源按祖島資源 ID、各島與當地資源 ID 穩定排序；優先祖島已解鎖庫存，再各島實際庫存。超額整列略去並累計 omitted；未被記錄的資源不能當零。

新遊戲、成功命令、轉世清空前補觀測；正式逐秒與快速離線在既有60秒年齡邊界採樣。分數年齡採該秒的真實年齡。舊聚合路徑或時間限定推進若跨過邊界，不重新切經濟計算或回填過去年份，只保留實際可觀測端點／轉世終點。這是稀疏觀測，並非逐年完整餘額。切小段與一次推進的經濟、RNG、帳目仍沿原契約核對；共同觀測位置按 Amount 值比較。正式多島逐秒／快速離線相同採樣位置已有專項驗證。

同年齡的成功操作覆蓋最後觀測，不宣稱保留每筆交易前後；交易明細仍由權威抉擇收據與資源帳表達。點數／字節超標時將內部點隔點保留，留下首點與最新點；再次超標仍可略去整列／點，明示 omitted。長壽不裁掉年齡上限、不把最後值填滿空隙。封存先壓縮觀測，再沿原抉擇／帳目限制收斂；不擴大原敘事預算。

容量是觀測時的規則總容量：建築／技能加宗門、天時與靈獸加成，祖島加工資源取既有 processing cap 上限，技能點沿 study cap；各島用原 storage capacity。它不是扣除預留後的可付款量，也不是所有命令必然共用的截斷規則（機緣原本可超容量）。有初始化副作用的乘區 API 只讀隔離的小型 GameState projection，不初始化原遊戲狀態、不抽 RNG。不改原收益、容量或運算順序。

`settlement={dao_heart,dao_proof}` 保存本次轉世原 reward 收據，與既有 end_state 的 settlement_id 同份封存。沒有欄位的舊世顯示未有紀錄；不以跨世總持有或更新後的公式重算舊世。尚在世不產生未提交的道果。獸魂仍由原系統／事件收據負責，不與兩種道果相加。

所有新欄位嚴格驗證版本、白名單結構、年齡順序與生命覆蓋、Amount／null、行數及字節上限；未知或損壞的子樹拒絕該候選，沿 SaveCodec checksum／兩代復原。兩代均壞拒絕覆寫；重試只保存，取消不採樣、不封存、不重發。

## 閱讀與圖表

輪迴 canonical route 增加共用 GameTab「歷世」，沿既有 CloseSeal、固定分頁、黑體16px資料、單一內捲與短橫式44px命中。年歲、終點境界／層、已得道心與道證分欄比較，各單位不加總；事實覆蓋與觀測覆蓋分開。選世後可讀同份凍結小傳、來源、資源帳與抉擇簿；不重新生成已封存文稿。

單一島別／單資源圖：同齡 X 軸、同單位庫存／容量 Y 軸、事件刻線；圓點庫存與方框容量。只畫已保留點，沒有連線／補值／因果或滿倉時段推論。正常數值線性正規化，跨層大數不轉 float，沿現有相對量級比值；極小值可壓到底線，畫面明示，完整 Amount 表為權威。缺觀測不畫假0曲線或0上限。

區間選擇含全世、四等分，以及相鄰真實觀測點的精確區間。精查採閉區間，邊界事件可在相鄰兩區出現；不是重複儲存。表列每個真實年齡、庫存／容量與事件本世序號、境界／層；機緣用收據題名，原完整收據另可展開。只有保留事件為空時顯示「未有保留事件」，不斷言沒發生。

保存保護的原唯讀內捲亦接歷世閱讀，原重試固定不動；讀史不解鎖世界操作。桌面1280×720、844×390、800×360按現行驗收；其他項目不擴大本輪範圍。

驗收與實際命令見 [REPORT-2](../verification/report-2.md)。
