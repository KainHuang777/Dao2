# ADR-012：保留一般技能並延續多島玩法

2026-10-05，使用者明確選 B：「保留舊成果中的技能功能，同時延續目前選定的多島玩法」。本決策只取代 ADR-011 的「一般技能／技能點暫不移植」段落；其 Era＋設施門檻、築基靈池與多島權威供給繼續有效。

技能功能從保留的 master ff86f85 適配到目前 Session／Amount／保存契約，並非整份 master 合併。原 master、codex/preserve-master-20261005，以及 VFX 保存分支完整保留。舊 Era2 的倍率、配方、資源來源與存檔模型不覆蓋目前主線。

## 採用規則

修行新增「技能」頁，六項為選修當世加成：基礎冥想（每階靈力產率×1.1，5階）、聚氣術（每階基礎靈力產率＋2，5階）、築基功（每階金錢產率×1.2，5階）、納靈法（靈力容量＋200，1階）、強身術（金錢容量＋2000，1階）、建築精通・初階（生產建築上限＋10，1階）。每階費依序為90／1800／3600／120／1000／200技能點；目前為工作平衡值，待人工節奏驗收。

築基後藏經閣產生技能點，首階金錢500／靈木200／下品靈石50／靈草20，最多3階，成本倍率1.8；產量採既有建築效果 `(level)^1.5` 與 Era／全局產率倍率，原 master 的產量6改成工作值1，不附加靈力。技能點基礎容量200；經書殿要求藏經閣1階，費金錢500／靈木500／下品靈石300／玄銅50，最多1階，增加6000容量。既有宗門、天時、靈獸的全倉儲加成仍適用，技能頁顯示實際容量。不可手動採集技能點。

建築精通只適用 wooden_house／forest_farm／stone_mine／herb_farm，並受內容自身 max_level 限制。茅屋、庫房、聚靈壇、築基靈池與研習建築不受影響。輪迴清除技能、技能點與研習建築；技能點不適用資源繼承天賦。

Era2 資源倍率2、修煉時間倍率1.2、境內靈力費200保持。築基→金丹仍查靈力容量2000，築基靈池每階＋1000、最多3階；不以技能解鎖金丹、島嶼、設施或配方。青木靈材／玄礦銅精／丹霞百年草与丹液／祖島加工分工、航運、當地庫存及扣料原則保持。
