# ADR-013：有界當世事實與九世封存

日期：2026-10-22。使用者指定 LEDGER-0，並明確回覆保存「9世」。此決定不接受卷末布局、題名條件或文稿。

## 決定

- 最多保留最近 9 個已封存生命。每世最多 64 個事件／32 KiB，當世 64 KiB，敘事子樹合計硬上限 352 KiB。UTF-8 JSON 鍵與值均計入，其他遊戲存檔、envelope、字串儲存與備份不計入此額度。
- schema5 加 `life_ledger`；敘事 version1。空字典表示未開始記錄／missing，無支援類別為 unsupported；已記錄支援類別使用 complete／partial。complete 僅指本版支援里程碑的觀測覆蓋，不承諾完整人生或經濟流水。
- 每個生命有存檔內單調 life_id、開始／覆蓋終點、觀測峰值、事件序號、略去計數、結束狀態與文字版本預留。life_id 的命名空間是該存檔，不是跨存檔全域 UUID。
- 事件最多 384 bytes；來源命令／結算身分經 SHA256 保存，避免任意長 command_id 撐大存檔。事件含實際年齡秒數、境界／層級、種類、主體、可選取得實例識別。相同年齡依實際核心提交順序排列。
- 第一批 48 事件固定保留，後 16 事件為最近環。建屋／開島／航線到貨／煉丹／研習／入宗／委託完成與領取／靈獸取得成熟／壽盡記首次已證明里程碑；進境、劫成敗保留不同來源的再次發生，以支援「劫後重行」。本版不是完整事件流水。事件超限略去整件並增加 omitted_count，覆蓋改 partial；不切斷 Unicode。峰值獨立更新。
- 凍結文字預留最大 4096 UTF-8 bytes，text_version 最多 64 bytes。LEDGER-0 不產生題名或小傳；後續 REPORT-1A 必須在同一容量與驗證契約內填入。
- 新檔從當世起點記 complete；舊檔從導入年齡記 partial，不回填建築、往世或 highest_era 為過去里程碑。當世峰值只是覆蓋範圍內的最高觀測值。
- 在轉世清空前，以最新狀態封存終點／原因／settlement_id，再建立下一世。與原道果共用同一 GameState 候選及保存協調。預覽只讀，保存重試不重新轉世；第十份封存只在轉世候選中淘汰最舊一份，持久層仍依原雙槽成功提交才視為落盤。
- 記錄不依賴 UI、節點、動畫、壁鐘或新 RNG。核心命令成功後記錄；時間推進中的宗門完成、航線到貨和壽盡在實際邊界記錄。快速離線亦按這些事實邊界分段，保留原運算與抽樣邏輯。

## 遷移與故障

SaveCodec 支援的 schema2／3／4 經原 checksum、欄位與經濟驗證後導入；首次寫新版本前，以 `save_before_ledger_<原文SHA256>` 備份及讀回核對。備份失敗阻止覆寫。修改舊的自動重置路徑：仍保留既有 schema1 rescue 行為，但不再將受支援的 2／3／4 當成新版本以前皆可清空。這是本任務的新舊檔保留政策，不把舊測試的 schema3 重置當作相容性證據。

未知敘事版本／錯型／額外無界欄位／超限均拒絕該候選，交由原 read_best 選另一合法槽；兩槽皆不合法則拒絕載入與覆寫。不能跳過 checksum、靜默丟敘事或假造空白進度。JSON 數字解析後依欄位恢復整數／浮點型別，確保原生 Dictionary 往返相等。

## 替代方案與界線

5／10／20 世提案改採使用者核定 9 世；未採無界歷史或逐秒流水。完整資源收支、權威實得機緣收據／pending instance、敘事選文與顯示頁各留後續批次，不預建完整帳簿。

`GameSession.get_life_record()` 回傳深複製；不將整個歷史加入逐幀 HUD View。`LifeLedger.coverage()` 提供四態查詢，不能把未支援類別顯示成已記錄的 0。

驗證與現況以 [LEDGER-0 驗收](../verification/ledger-0.md) 為準，該頁保留初輪失敗，不以本 ADR 代替測試。
