# ADR-009：Era 解鎖多島資源鏈與實際物流

日期：2026-10-03。狀態：方向依使用者要求採納；數值與分段內容為工作方案，runtime 尚未實作。

## 背景

使用者明確指出預想包含 Idle Planet Miner 類型的產地升級、加工融合、供給運輸，以及 DAO1／貓國物語／Evolve 的多階資源依賴。現行遠景多為装飾，跨界主要換題字／色調，少量靈界轉換不足以呈現該核心循環。DAO1 的靜態資料含 61 資源／30 配方，DAO2 manifest 僅 7 資源與 Era 1–2；不能用子系統數量代替內容深度。

## 決策

1. 多島產業列為主線 RES1：Era 解鎖島／配方，專業島採集與加工，T2 再加工為 T3，材料被設施／修行消耗，物流吞吐影響實際供給。
2. 空島不是 Era 編號；一境可解鎖多島，人界也可有多島。九界仍是法則環境，資料概念保持分離。
3. 先做手工 Era 1–3 可玩鏈，DAO1 ID／來源／需求優先核對；新增靈材／陣芯、時間和運輸列為 v2 變更，不宣稱 legacy_parity。
4. 多島以地方庫存與在途狀態表達物流。保留 Godot/GDScript 與純核心確定性，動畫不發獎；新增版本、遷移、故障復原／重試與輪迴契約。
5. 不重排十個漂浮地塊到目前島圖。新島有各自地形、少量地標與 Banner；清單管理同一份設施資料。資源與吞吐說明先於純裝飾擴充。

## 取代與保留

- 修訂 docs/03 ADR-002「物流首版只呈現供給」的後續範圍：歷史實作保留，但新 RES1 正式加入規則物流；模擬／動畫分離仍有效。
- 修訂 docs/08：單島清單是既有版本的呈現策略，不是禁止新的資源島；每個新地標仍需美術與命中驗收。
- 修訂接手順序：RES1-A 為下一工作，M1-C/D 與新經濟狀態相交的保存／離線驗收是 B/C 正式放行門檻；M5 無限生成擴張排在手工產業證明之後。
- 既有 M4-A-R1 DONE 只保留原整合範圍；不代表已完成多島／多階資源。

## 代價與放行

地方庫存與航線增加時間邊界、遷移與 UI 複雜度，故採固定少量航線／預設自動運輸，先驗三島，再增 Era 3 第四島。精確島名、解鎖數量、成本／時間於各切片測試調整，不能把暫名變成全十二境的內容承諾。

放行須有一條 T1→T2→T3→實際升級需求鏈、至少一個能被運輸或產能升級改善的瓶頸、無後階材料鎖住前階解鎖、離線／切景收益一致、保存重試不重發、真實 Web 與使用者玩法驗收。
