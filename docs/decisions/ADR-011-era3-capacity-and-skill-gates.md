# ADR-011：金丹前置容量與技能替代

2026-10-05，RES1-D2。使用者明確選擇 **Era＋設施門檻，新增築基擴容設施**。這是 v2 決策，不宣稱一般技能或 DAO1 數值完整承接。

原聚靈壇 `storage_lingli` 每級容量100、全域上限10保持；築基期可建 `foundation_reservoir`（築基靈池），聚靈壇2級為前置，每階增加靈力容量1000，最高3階。首階費金錢100／靈木50／下品石20，後續費倍率1.5。基礎100＋聚靈壇2級200＋靈池2級2000＝2300，足額達到築基→金丹容量2000。突破仍查容量，不扣同額庫存；不要求金丹產物。

一般技能／技能點暫不移植，也不借宗門功法假裝承接。丹霞在築基管理頁可見，金丹才可開拓；T1木20／石10由祖島支付，包涵首級採集／工坊／倉儲與基本航運。百年草唯一來源丹霞，丹液唯一加工者丹霞；祖島共用靈力付加工費。木島靈材、礦島銅精、祖島陣芯／築基丹／中品石／金丹丹藥／符咒的分工由核心拒絕錯島命令保護。

金丹境內費採 D1 的 DAO1 時間／基礎成本與 Lv9符咒字面，加丹液1及陣芯1為 v2 初始平衡值；不等於已有人類節奏驗收。金丹丹藥是物品，尚無服用效果；Era4未提供，不把它當築基→金丹突破費。無正式一般技能點、合成暴擊或全量大數承諾。

正常主場景沿既有 `IslandProgression.attach` 附掛經 `ContentLoader.build_content` 驗證的 `content/buildings/era2.json`、`content/eras/era3.json`；基礎 manifest／独立舊規則載入器保留 Era1/2。加工資源仍在啟用命令加入權威祖島庫存，非第二份 Production 庫存。D2合約版本 `res1-d-2`、rules `core-flow-10-danxia`，schema3資料形狀不變；舊 C 不自動改版，保留可回復 JSON 後候選提交。輪迴保留原合約版本並清除當世工作、貨物、設施及丹霞。

本輪正常管理頁可操作丹霞，尚無專用世界美術與世界入口。不得借青木／玄礦美術冒充丹霞。D2／完整D的瀏覽器、裝置、美術、玩法與C/R2剩餘驗收逐項記於 [D2驗收](../verification/res1-d2.md)；本ADR只核定方案與實作工作值。
