保留紙面、霧青玉選中及金底線、黑體數據、44px操作與單一叉號關閉的共同方向。正式落地仍須使用 GameTab／CloseSeal／容器，不能將 HTML 原型取代 Godot。圖像在此只比較布局，無新生成美術。
