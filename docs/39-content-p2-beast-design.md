## 4. 地方通道、對照與瓶頸

新增兩個純函式：`BeastSystem.local_rate_multiplier(state,island,resource)`與`local_capacity_bonus(state,island)`，只讀狀態、正式版本與白名單，不讀Node／Texture／RNG。僅新版獸狀態作用。地方產率：

`既有rate（基礎×當島調度×1.1^技能階×(1+0.1×拓脈階)×古藥丹倍率）×(1+本獸階段被動)`。

SKS地方技能0–3階、拓脈0–5階、古藥丹1或1.5；獨立乘區，其他已存在乘區不改。卵／無獸／其他獸／錯島／錯資源返回1。成熟無T1的裸基礎精鐵0.1→0.12／秒、秘銀與寒鐵0.05→0.06、千草0.04→0.048；T1成熟分別0.121／0.0605／0.0484。調度仍原2倍，沒有翻倍獸魂收益。地方滿倉或航線未送出時，增產可能全數無法入庫；收益帳仍列產生／實得／未入庫，不承諾落到祖島。

地方容量：`300 + 100×frontier_storekeeping階 + 本島T4的30`；技能0–3階時300／400／500／600→330／430／530／630。固定加30而非乘10%，不放大已核定SKS庫容。開島前容量查詢不因獸魂新增可用庫存；祖島的雲蛟／宗門／天時／丹藥／玄龜容量不混入地方公式。

接線至少核對IslandEconomy.rate／tick／tick_prepared、TimeAdvancer準備與失效、IslandProgression.capacity、容量預留／航線到貨與帳本View。當世餵養升階、T1／T4領悟、取得及輪迴後，快取必須即時失效；離線逐秒準備不能持有舊獸狀態。舊四獸的compute_multipliers字典與祖島time／cap邏輯保持原值。

| 取捨 | 收益與成本 |
| --- | --- |
| 霜角鹿 vs 玄龜 | 當地三礦增產對祖島石／鐵庫容+25%；鹿不補祖島滿倉，龜不提高地方採速。原始20餵少400精鐵＋1600下石支出，但新增400靈草需求；不同資源不可相加作淨收益 |
| 銜芝鶴 vs 火鳳（Era6） | 地方千草增產對修速+15%；無天賦鶴需40千草＋100百草，鳳200千草。鶴Era5可先結契，但Era6不能改鳳，沒有同世兼得兩被動 |
| 新獸 vs 靈狐 | 高境供給對成熟金錢產率+20%；不把靈狐看成零成本替代，亦不強制早期玩家留空結契位 |
| 新獸 vs 拓脈／地方技能／丹藥 | 拓脈跨世全三島、技能只當世、丹藥古藥限時1.5；獸占單世槽並需手動餵。獸不花道心，不降低道心持有加成；無新天賦也能走R46主線 |

裸產率、無堵塞且成熟後持續採集：鹿需額外產鐵200所需200÷0.02=10000秒，鶴額外千草40所需40÷0.008=5000秒。這是「成熟後以增量產出等量餵料」的尺度比較，忽略成長期已增產、不抵其他餵料／機會成本／運輸，**不是整體回本時間**；有限生命週期可能不回本。兩獸各服務不同產線，不改色複製同全局倍率。
