## 2. 三項共通取得與拒絕契約

建議新三項全用五階；每階10／20／40／80／160，累計10／30／70／150／310道心。一項全滿按每世25保底、零起點無其他消費需13次；三項930需38次，這只是保底預算除法，不是自然世數或遊玩時間預測。已有道心與更多建築會改變結果。較P1一項155提高一倍，屬本次已核定節奏。

三項皆要求 `reincarnation_count >= 1 && highest_era >= 4`；不用當世era限制購入，也無realm條件。未曾元嬰仍可查看鎖因；首次元嬰輪迴後至少有25保底可選一項首階或兩項首階。最高境界沿權威狀態，不讀UI／成就替代，不增歷史補發。已購入跨世保留，即使當世退回練氣也保留資格；效果只在適用系統正常解鎖後產生。

修行→輪迴→天賦沿 `learn_talent` 命令；只花道心，不花道證／獸魂／材料，無宗門前置或互斥。缺道心／最高境界不足／未輪迴／滿階／未知ID／非法版本都整筆拒絕。新門檻失敗建議 `TALENT_REINCARNATION_REQUIRED`、`TALENT_HIGHEST_ERA_REQUIRED`；既有六項門檻與拒絕順序保持。先驗版本／ID／階數，再驗新門檻、滿階、道心，拒絕無event／扣款／revision變化。

購入立即對後續行為生效，不追補已服丹、已付加工／餵養費、過去採集或封存帳目。購買成功必須先保存；保存失敗沿現行只保存重試，不再次執行learn，不另發起手資源。

## 4. U2：拓脈宿慧

ID `frontier_prospector_memory`。固定島白名單 `deep`寒銀／`ancient`古藥／`void`太虛，固定資源精鐵／秘銀／寒鐵／千年靈草／虛空精華。對各島既有採集 `原率 × 調度倍率 × SKS-P2地方技能倍率 × (1+.10L)`。只在SUPPLY_VERSION且該島已開時生效；白名單島與資源須同時符合。青木／玄礦／丹霞、祖島全部排除；未開島收益0，仍可購入並在卡片明示。

滿階×1.5，不複利1.1^5；與當島技能乘算，不改祖島Production表，也不把道心全產倍率塞入遠島。採集共用 `IslandEconomy.rate`，一般tick、跳時計算、stationary偵測及View用同值；購買後使prepared／View快取失效，線上離線須一致。庫容、貨船容量、10秒航程、航線啟用、當島調度建造費與工作預留保持。滿地方庫仍停止入庫，不把超額變成祖島收入。

寒鐵原率0.05/s，無調度／無地方技能、空庫且無航運時，30單位連續供給600秒；一階0.055/s約545.45秒、按秒邊界546；五階0.075/s為400秒。精鐵原0.1/s、千年草0.04/s、虛空精華0.05/s均同倍率；調度×2後一階寒鐵0.11/s，地方技能照原倍率另乘。這是採集算例，不是祖島可用料等待；船運／缺容量可能讓增益無法轉成吞吐量。

百工只增祖島四設施，這是三座遠島專長；與升調度×2比較，一階+10%較小但付跨世道心，調度付當世材料且每世重建。兩者可並用，沒有跳過開島或免費起手。零技能主線證據仍有效，U2不成開島／晉階前置。

## 6. 道心機會成本與替代方案

`G(H)=1+.15log10(H+1)`只沿既有祖島持有乘區；道證相同。花費S後未獲直接補償的祖島產率為 `G(H−S)/G(H)`。具體小數與所有可負擔三新項階數組合見[靜態算表](verification/artifacts/content-p2-talent-design/analysis.json)，涵蓋H20／25／50／100／310；H20只作持幣比較，仍須通過最高境界與輪迴門檻。

H25可一項首階10（餘15）、兩項首階20（餘5）；未受補償祖島產率分別剩97.391%／92.120%。單項二階累計30與三項各一階30皆不可負擔。一階U1省4%直接草，卻降低其他祖島備料產率；U2遠島+10%不直接承受G損失，但祖島開拓／調度材料仍變慢；U3每餵60經驗，不直接承受G損失，但草料／石料準備受影響。滿倉／零產出／未取得獸時收益可為0。

同預算10也可買資源傳承首階5或P1任一首階5而保留更多道心，或長生久視首階10。預算15可買先天道體首階；P1靈契5只加靈狐經驗，本項10只加玄龜／火鳳，不能把同+20%寫成全獸升級版。P1丹心與U1服務不同丹種；百工不涵蓋遠島。所有算例不替代同版合法命令／自然代表路徑或人工節奏接受。
