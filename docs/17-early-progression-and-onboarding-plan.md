## 4. 卡關與相依分析

1. **築基一次湧入系統**：入口可见不必等於自動彈出教學。先集中雙島首批供給，再介紹技能、宗門；取得資格仍依原規則。第一次築基的具體先後尚待核定。
2. **雙島原料不是配方循環**：青木木材和玄礦石／銅皆為採集源，`ore_wood` 可用1階免費航線啟動，故沒有「先有靈材才能取得靈材」的必然閉環。但若教學先要求升運力／加工坊，就會自己製造 T2 前置死結。首教只用初始1階。
3. **丹藥名稱與升境條件不一致**：築基丹是產率支線；`golden_core_pill` 是 Era3 內道具，需築基丹3＋百年草2＋中品石5，不是築基進金丹的鑰匙。其用途後續另核對，首升級不要求製作。
4. **容量台階**：練氣茅屋額外容量在築基消失，不能拿練氣畫面容量預測築基。聚靈壇／築基靈池和庫房的具體缺料從 View 取，不能只有「等待產線」而忽略满倉。
5. **共用材料競爭**：技能建築、工程、航線升階及陣芯會爭用祖島料；丹霞草回運與丹液加工會爭用地方草。提示应先解釋哪一庫存、保留量與目前工作，首段不強制全設施升階。
6. **進度觀測缺口**：目前库存可作「現在能否操作」判斷，不能證明曾服丹／曾到貨，因為產物可能已花掉。`command_receipts` 僅保留最近256筆，不能當永久教學歷史。F4等歷史節點需後續有界持久化設計。
7. **等待與壽元**：現有D2命令流程可通，但使用加速模擬時間，不能據此宣稱自然等待節奏合理。下一實作必須記錄新檔各段自然耗時、等待來源及壽元餘裕；不因本文件而改成本或時間。

- 輪迴依原規則重建當世產業；保留「已介紹」偏好，讓熟悉玩家使用精簡目標與自行重看。是否保留偏好及欄位需下一階段定案；不可為略過教學保留已清除的材料／靈獸。
- 已輪迴玩家練氣即有宗門資格，不能套首次玩家的Era2鎖。低境界回鍋與舊三島版本需分別驗，不因最高境界推斷當世資源充足。
