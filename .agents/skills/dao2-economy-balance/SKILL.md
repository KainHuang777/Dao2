# Dao2 數值平衡與產銷循環設計

本技能專用於 Dao2 經濟循環、配方成本、島嶼運力與境界升階條件的數值平衡審查。當涉及產出公式、工坊耗時、運輸配額或升級要求變更時調用，確保資源「產能 → 運輸 → 倉儲 → 加工 → 晉升」全鏈路健康閉環。

## 審查核心清單

### 1. 產銷速率與吞吐平衡（Throughput & Bottleneck Ratio）
- **採集 vs 加工吞吐**：上游島嶼（如採集浮島）的產出速率（單位時間產量）必須略大於或等於下游工坊（如製造工坊）的額定消耗速率。避免出現上游長期匱乏造成工坊停擺。
- **運輸承載瓶頸**：計算單條航線的單程時間、載重量與往返頻率：
  $$\text{Effective Transport Rate} = \frac{\text{Capacity}}{\text{Trip Duration}}$$
  運輸吞吐必須大於下游消耗速率，否則即使上游爆倉，下游也會因運力不足而飢餓。

### 2. 空等時間與節奏分析（Pacing & Idle Time）
- **並行活動排除**：計算達成特定里程碑（如 Era2 升級第二階）的純等待時間：
  - 扣除玩家在島上探索、布設、調整配方等可同步進行的操作時間。
  - 若純待機等待時間超過當前境界合理門檻（如早期階段純等待超過 60~90 秒），即屬「數值節奏過慢/卡點」，需考慮調降首批配方批量、縮短往返時間或提供即時採集途徑。

### 3. 倉儲上限與溢出保護（Buffer & Deadlock Protection）
- **安全庫存與溢出**：各節點緩衝倉儲容量至少應容納 2~3 個運輸批次，避免因下游滿倉導致整條航線卡死。
- **保留量門檻防護**：侍女職責或自動化運送的「原料保留量（Reserve）」設定，預設值不可大於該階段的產出上限，防止自動化邏輯因保留門檻過高而永遠拒絕動用原料。

### 4. 晉升消耗門檻（Progression Gate & Payback）
- **晉升成本階梯**：境界升階所要求的資源組合（如銅精、靈木），其採集與提煉總耗時需呈現平滑指數增長，嚴禁出現跨階時的斷崖式暴增。
- **解鎖反饋即時性**：晉升新境界或開啟新島嶼後，必須立即賦予玩家可感知的收益（例如新配方、新建築或更高速的採集位），維持玩法正向反饋。

## 輸出結構
審查完畢後輸出：
1. **鏈路流量模型**（上游產出、航線運力、下游工坊消耗比）。
2. **瓶頸與等待點預警**（指出哪一段成為木桶的最短板）。
3. **數值調優建議**（具體的參數調整：如批次數量、生產秒數、保留門檻等）。

流程參考 [Claude Code Game Studios 的 economy-designer 與 balance-check](https://github.com/Donchitos/Claude-Code-Game-Studios)。
