Decorative text is `ॐ मणि पद्मे हूँ` (Om mani padme hum), line-broken at complete word groups. It accompanies the Chinese realm names as a repeated mantra; it is not a Sanskrit translation of those six names. Each complete group is shaped by Godot's text renderer. No code-point-per-line split or invented glyphs are used. Character coverage and rendered appearance checked separately. The wording is a visual candidate, not an assertion of ritual/textual edition accuracy.

Used only for six upright vertical decorative pairs in the isolated reincarnation trial. Controls use the existing Dao2 Sans font. This is a WenKai brush-like candidate for visual review, not a claim of accepted heavy calligraphy. All twelve characters are checked with Godot Font.has_char during native capture. No system installation or font substitution.
