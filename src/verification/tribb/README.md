# TRIB-B isolated presentation source

Godot 4.7.2 / Compatibility / single-thread Web. Build with `tools/build_trib_b.ps1 -ExportWeb`; inspect `build/web-trib-b/index.html` through a loopback HTTP server. `.gdignore` prevents the nested project being imported by the production project.

`stage.gd` reads an explicit 0–20 second visual clock. No GameSession, inventory, save, command, progression, or gameplay RNG is instantiated. Success/failure is a preview selection, not a prediction or rule implementation. Ground shadow and terrain share the island plane; each character pose uses TRIB-A's measured core anchor. One half-resolution background SubViewport is distorted separately from the full-resolution character, lightning and controls. Source plates have 1.32 overscan; radial sampling moves inward to prevent stretched clamped edges. Glow is an original additive 25-tap blur of the existing per-pose mask.

`sound.gd` is original procedural PCM synthesis. TRIB-B-F1 (2026-10-19) adds distant cloud thunder at 0.65 and 3.65 seconds, replacing the old sine-chirp strikes with filtered-noise cracks, delayed bass/mid thunder and irregular rolling decay at 7.6/9.3/11.1 seconds. Four asymmetric stereo reflections follow; outcome tones stay quieter behind the storm at 12.4 seconds. No downloaded audio or third-party samples. Smooth saturation leaves PCM headroom before an additional -5 dB live gain, with a silent ending. Muted by default; audio starts only through the preview control. Pause, seek, replay, focus loss, skip and exit stop/reposition the stream. This project has no production BGM to duck; production audio buses and user settings belong to TRIB-C. Musical/visual taste still requires user acceptance. `audio_check.gd` exports both revised WAVs and checks playback lifecycle without rerendering unchanged visual frames.

All images reuse accepted TRIB-A assets, prompts and source hashes in `assets/tribulation/trib-a/manifest.json`; terrain reuses `assets/abode/fx3art1/terrain.png`. No new raster assets or font sources. Existing source-concept commercial-rights qualification remains. Shaders, synthesis and staging code are original project code. Captured PNG/WAV/MP4 are verification outputs, not production texture or audio replacements.

`capture.gd` renders both outcomes at fixed explicit times (12 capture frames per second), with three desktop layouts and lifecycle/anchor/control checks. These captures are not a measurement of runtime FPS. Build copies the generated `.uid` sidecars back to this source folder. Modify source here, never generated build files.
